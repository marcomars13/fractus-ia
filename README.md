### 🚀 Overview

**Fractus** is a universal anomaly detection framework based on **fractal laws** and **adaptive geometry**.  
It models irregularity, compression, and signal coherence through a recursive mathematical process inspired by natural fractals — offering a bridge between **mathematics, pattern intelligence, and conscious modeling**.

This project unites:
- 🌀 **Fractal compression law (Fractus)** — self-similar recurrence model  
- 🌍 **Geospatial correlation (Plonk integration)** — Earth-scale validation  
- 🔭 **Cross-domain anomaly mapping** — astronomy, security, biology, AI  
- ⚡ **Solana blockchain validation** — tokenized proof-of-concept  
- 🧠 **Mirovia AI integration** — reflective layer for interpretation and ethics
